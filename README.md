# Locar Útil AutoCheck

PWA responsiva para abertura de chamados, coleta, vistoria, registro fotográfico de avarias e entrega de veículos.

## Teste inicial

Abra `index.html` ou publique com GitHub Pages/Cloudflare Pages. Os dados da versão inicial ficam no armazenamento local do navegador. Para uso simultâneo em vários aparelhos, conectar posteriormente um backend gratuito com autenticação e armazenamento.

## Instalação

No Android/Chrome, abra o endereço publicado e selecione **Instalar aplicativo**. No iPhone/Safari, use **Compartilhar > Adicionar à Tela de Início**.
