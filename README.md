# Locar Útil AutoCheck

PWA responsiva para abertura de chamados, coleta, vistoria, registro fotográfico de avarias e entrega de veículos.

## Novidades

- Chamados sincronizados em tempo real entre computadores e celulares.
- Fotos e PDFs armazenados online, sem ocupar o pequeno limite do navegador.
- Seleção de fotos diretamente da galeria do celular.
- Limite de 20 MB por arquivo.
- Botão **Baixar / abrir** nos arquivos arquivados.

## Ativar o Supabase gratuito

1. Crie um projeto em https://supabase.com.
2. Abra **SQL Editor**, cole o conteúdo de `supabase-setup.sql` e execute.
3. Em **Project Settings > API**, copie a URL do projeto e a chave pública `anon`.
4. Preencha esses dois valores no arquivo `config.js`.
5. Publique a branch principal no GitHub Pages.

> A chave `anon` é pública e própria para uso no navegador. Não coloque a chave `service_role` no repositório.

## Instalação

No Android/Chrome, abra o endereço publicado e selecione **Instalar aplicativo**. No iPhone/Safari, use **Compartilhar > Adicionar à Tela de Início**.
